# Contributing

Read AGENTS.md and the owning service skill. Create/reuse an issue, scope it to a target SemVer milestone and open a linked PR. Preserve one candidate version through review. Run the README checks; include actual outcomes and distinguish local tests, CI, publication and tenant verification. Never commit customer data or credentials. Use synthetic fixtures/screenshots and update affected service documentation/continuation.

No direct main pushes, force-pushed shared history, failed-check bypasses, recycled tags or overwritten npm versions. API changes belong in SalesDrone first; this adapter cannot bypass policy. New tools require fixed GET routes, strict schemas, read scopes, bounds, protocol tests and safe observability. Update the README permission table and service catalog.
