# Project brief

An independently distributed local stdio MCP adapter for authorized current SalesDrone reads. Users connect their chosen MCP host using a scoped PAT, discover 21 GET tools and read one bounded page at a time. No hosted MCP, write operations, direct Firestore, presence inference or employee scoring. API policy stays in SalesDrone. Owner: theharithsa / Avinya Enterprises. Node 22 ESM, official MCP SDK v2, npm distribution. Human decisions are recorded in project.json.
