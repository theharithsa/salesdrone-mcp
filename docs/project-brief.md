# Project brief

An independently distributed local stdio MCP adapter for authorized SalesDrone reads and explicitly requested writes. Users connect their chosen MCP host using a scoped PAT, discover 21 GET tools plus 20 documented PAT operations and read one bounded page at a time. No hosted MCP, unlisted/Google-only operations, direct Firestore, presence inference or employee scoring. API policy stays in SalesDrone. Owner: theharithsa / Avinya Enterprises. Node 22 ESM, official MCP SDK v2, npm distribution. Human decisions are recorded in project.json.
