SalesDrone MCP 1.1.0 moves the read-only adapter into its own repository while preserving the npm name and stdio tools. It adds opt-in metadata-only OpenTelemetry traces/logs/metrics, independent protocol/wire/privacy checks, synthetic screenshots, main-only OIDC npm publication and source-confirmed Dynatrace lifecycle events.

The package still relies on current SalesDrone HTTP authorization. Team reports represent recorded work, not presence or performance ratings. Runtime telemetry is disabled by default. See README for configuration, privacy limits and migration history.
