# MCP server

Owner theharithsa. Active Node 22 ESM service, entry src/cli.js; src/server.js owns 21 strict read tools plus 20 Swagger-derived PAT operations in src/write-tools.js, src/api-client.js owns fixed documented method/path allowlists/HTTPS/PAT/deadline/concurrency/body limits. SalesDrone API 1.29.0 owns policy and data; never access Firestore or expose Google/App Check-only or unlisted operations here. Keep current reports distinct from presence, performance and historical snapshots. Follow sparse cursors. Private reminders remain private.

src/telemetry.js initializes one opt-in provider lifecycle with bounded queues/shutdown, user's lean McpInstrumentation class and explicit v2 callback bridge. No /register auto-patching, inputs/results, IDs, tokens, URL queries or raw exceptions. Runtime service salesdrone-mcp; version/build identity from scripts/build.mjs. Preserve root/HTTP child/log correlation and safe metrics. Invalid/export-failed telemetry must not fail reads or pollute stdout.

Run npm test/check/security:scan and dependency audit, plus foundation checks. test/protocol.test.js exercises real stdio/all tools; telemetry.test.js independently decodes OTLP and tests privacy/concurrency/export rejection. Capture docs harness with synthetic data only, record hashes and actual viewport. See README, docs/observability.md and docs/delivery.md. Source changes require linked checked PR and new SemVer after publication; main publishes via OIDC, no tag/version recycling. Read continuation before work.

The source of truth is reviewed docs/openapi.json, projected into packaged src/write-contract.json by scripts/sync-api-contract.mjs. Run its --check gate. Write schemas derive directly through Zod JSON Schema conversion, preserving strict bodies, unions, limits and concurrency fields. Path IDs reject traversal. Pass explicit UUID idempotencyKey only where Swagger requires it; never generate one or retry automatically. Timeout/cancellation/response failures leave commit status uncertain. Re-read before retry and preserve original key/body. Base64 uploads are canonical and decoded at most 8 MiB, JSON at most 10 MiB. No file paths or URL fetches. Mutation hints are conservative; preview/export are read-only. New HTTP methods must appear in safe telemetry with normalized attachment/activity/notification routes and no values. test/writes.test.js covers all 20 real stdio routes, contract parity, validation, conflict/denial, binary bounds and uncertain outcomes.

For postpublication evidence run protocol/write suites with MCP_TEST_ENTRY pointing at the clean registry-installed CLI, verify npm signatures/provenance and keep helper-only tests distinct from installed stdio execution. Dynatrace spans use trace.id/span.id/span.parent_id while the configured log pipeline retains trace_id/span_id; compare actual IDs across records rather than assuming identical field names. Bind CI cases to exact source run/artifact and re-query ingestion lag before concluding missing cases. See docs/releases/1.2.0.json for the verified release evidence.
